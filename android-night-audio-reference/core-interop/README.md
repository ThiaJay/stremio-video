# Stremio Core Kotlin read-only interoperability laboratory

**Development module only; not included in the Fire TV companion APK.** This is a source-typed adapter using the official archived `Stremio/stremio-core-kotlin` `1.15.0` public Core SDK. The code compiles the Core `getState<Ctx>` / `getState<MetaDetails>` ABI with the exact official package, and returns a narrow read-only snapshot without exposing account keys, emails, auth IDs, addon URLs or video stream URLs. Its access checks require a live host-supplied session epoch and second read of metadata to reject account or media switching.

The official SDK itself declares Android INTERNET and ACCESS_NETWORK_STATE permissions. This isolated lab uses the dependency as **compileOnly**, does not include its AAR/JNI in the synthetic Android TV app, and does not add either permission to that app. It does not initialise, authenticate, dispatch, synchronise, query installed personal addons or play a real video. In particular the official Kotlin 1.15.0 `ActionPlayer` protobuf schema does **not** include the newer generic `DismissSkipSegment` variant used by the forked shared Core: this requires an independently pinned ABI upgrade, not a fabricated call.

The source runs separate JUnit tests of a fake read-only provider. Android CI must compile this module against the reviewed official SDK, run all eight tests, verify that the main companion still has zero permissions, and emit **no installable artifact**. It may fail if the archived SDK cannot be resolved; record rather than weakening the dependency or redirecting to an unreviewed fork.

Remaining native stage: licence/notices and transitive security review, stable account lifecycle epoch producer, approved SDK source/JNI rebuild with current Core protobuf skip action, signed-in dedicated **test** account readback and guard verification, provider stream selection, original history backup and conflict-safe writes, permitted internet/account permissions and explicitly approved eventual installation. Do not import private profile storage from the installed official Stremio app.
